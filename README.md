# HR Analytics Dashboard

## Project Overview
An end-to-end HR analytics project designed to analyze employee headcount, attrition, engagement, performance, satisfaction, overtime, and tenure trends using Excel, PostgreSQL, SQL, and Power BI.

## Objectives
- Analyze workforce distribution across departments and job levels.
- Calculate employee attrition counts and rates.
- Explore relationships between attrition, overtime, tenure, engagement, and satisfaction.
- Present workforce insights through an interactive Power BI dashboard.

## Tools and Technologies
- **Excel:** Initial data preparation and validation
- **PostgreSQL:** Data storage and SQL-based analysis
- **SQL:** Aggregation, conditional calculations, and data validation
- **Power BI:** Interactive dashboards and visual analytics
- **DAX:** KPI measures and dynamic calculations

## Project Workflow
1. Prepared and validated the employee dataset.
2. Imported the dataset into PostgreSQL.
3. Executed SQL queries to analyze headcount and attrition.
4. Connected Power BI to PostgreSQL.
5. Developed dashboard pages with KPI cards, charts, slicers, and employee-level drill-through analysis.

## Key Features
- Employee headcount and attrition KPIs
- Department-wise attrition analysis
- Attrition analysis by overtime and job level
- Engagement, satisfaction, and tenure analysis
- Interactive filtering and drill-through exploration

## Dataset

## How to Use
1. Import the dataset into PostgreSQL.
2. Execute the SQL queries in `hr_analytics.sql`.
3. Open the Power BI report and configure the PostgreSQL connection if prompted.
